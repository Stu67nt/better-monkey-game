### Overview
better-silly-banana-shooting-monkey-game is a funny brainrot bullet hell game where a banana has to surive a storm of monkeys trying to eat it, by running away and shooting them with its friends and familie \:). It features multiple upgrades and a highscore system.

### Installation
The game can be run by running the `better-monkey-game.exe` file inside the folder which can be downloaded [here](https://github.com/Stu67nt/better-monkey-game/releases).

### Proccess
We started making this game with a terminal rendering module which didn't really work out, so we switched to using pygame and just making it a normal executable.
We then proceeded trying to make a serious high quality game which we then abandoned and turned it into in a meme game.
