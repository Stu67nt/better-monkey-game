### Overview
better-silly-banana-shooting-monkey-game is a funny brainrot bullet hell game where a banana has to survive a storm of monkeys trying to eat it, by running away and shooting them with its friends and familie \:). It features multiple upgrades and a high-score system.

### Installation
The game can be run by running the `better-monkey-game.exe` file inside the folder, which can be downloaded [here](https://github.com/Stu67nt/better-monkey-game/releases).

### How-to-Play
Once you boot up the game, you can instantly start playing. Hold left click to shoot bananas in the direction of your mouse. Use WASD to move! Monkeys will run towards you, and you should shoot them with the projectile bananas to kill them. There will also be power-ups which you can collect to upgrade your movement speed and fire rate. Try to survive as long as possible! 

### Process
We started making this game with a terminal rendering module, which didn't really work out, so we switched to using PyGame and just making it a normal executable.
We then proceeded to try to make a serious, high-quality game, which we then abandoned and turned it into in a meme game.
